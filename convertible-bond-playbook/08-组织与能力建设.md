# 08 组织与能力建设

流程写在纸上不会自动运转。权益短板阶段，组织设计要服从一句：**少而闭环，先把 P1.0 做对。**

## 1. 起步编制（最小闭环）

不必单设庞大权益部。最小配置：

| 角色 | 人数（可兼职） | 关键产出 |
| --- | --- | --- |
| 转债投资经理 | 1，可由固收投资经理兼任 | 模块装配、组合、退出 |
| 信用研究 | 从现有信评覆盖转债发行人 | 入库、债底、观察名单 |
| 数据/量化支持 | 0.5 | 双低、溢价中枢、条款计数 |
| 交易 | 现有交易所债券交易岗 | 下单、强赎窗口交易 |
| 风控 | 现有市场风险岗明确转债科目 | 限额、Delta、压力测试 |
| 运营估值 | 现有估值岗 | 取价、转股在途、净值 |
| 产品 | 1 | 谱系、文本、渠道翻译 |
| 合规 | 现有产品合规 | 登记、适当性、宣传 |

投委会中至少一人能问出：这只券债底还在不在、现在是债性还是股性、强赎还有几天。

## 2. 分工边界

- **投资经理**对组合风格是否符合产品负责，不能把风格漂移解释成“市场变了所以我变成股票基金”。
- **信用研究**对债底负责，有权把券打入观察/禁投，投资经理不能用“转债有期权”否决信用结论。
- **风控**对限额和分类负责，不负责选券。
- **产品**对说明书与客群匹配负责，不向投资经理下达“这个月必须多赚 20bp”的指令而不给风险预算。

## 3. 考核

| 对象 | 建议指标 | 避免 |
| --- | --- | --- |
| 投资经理 | 产品绝对收益、回撤、信息比、违规次数、强赎零事故 | 按转债仓位高低发奖 |
| 信用研究 | 入库准确、漏报事件、覆盖时效 | 只考核推荐数量 |
| 产品 | 文本零缺陷、渠道投诉中的误导类 | 只考核募集规模 |
| 风控 | 拦截有效性、报告及时 | 事后追责替代事前限额 |
| 渠道 | 适当性、话术抽检合格率 | 只考核销量 |

P1.0 的规模考核权重应低于纯债产品，避免渠道为冲量把转债产品卖给最低波动偏好客户。

## 4. 能力进阶路线

```text
阶段 A  信用覆盖转债发行人 + 条款日历跑通
阶段 B  规则化 M2 小仓位运行，有归因
阶段 C  能独立解释转债桶盈亏（估值 vs 正股 vs 信用）
阶段 D  引入红利/指数股票，仓位低于转债
阶段 E  评估主动行业研究是否值得建组
```

每个阶段的门票是上一阶段的事故率为零、回撤在预算内。不要用招聘人数定义阶段。

外部智识可以买，决策不能外包：

- 卖方转债周报、条款数据库：可以用。
- 公募转债基金、转债 ETF：可以作为研究和卫星配置，但 P1.0 建议以直接投资为主，避免叠加一层产品风险和费用后再说不清持仓。
- FOF/MOM 外部转债策略：适合作为对照，不适合在自身流程未建时成为唯一实现方式——否则公司永远不会具备条款处理和客户解释能力。

## 5. 系统建设优先级

1. **拦截：** 池、限额、现金管理类黑名单。  
2. **条款：** 强赎/回售/下修倒计时推送。  
3. **估值：** 自动取价与例外流程。  
4. **归因：** 转债桶独立。  
5. **Delta 与压力测试。**  
6. 研究平台、因子库（可后置）。

## 6. 培训清单

**投研交易：** 条款、指标、风格、强赎演练、交易规则（20% 涨跌幅、临停、无效申报）。  
**风控运营：** 分类、转股、估值例外、披露时点。  
**渠道：** 转债是什么、与股票/纯债区别、R 等级含义、不承诺收益。  
**高管/投委会：** 两本账（外规债权 vs 内控波动）、何时允许提高限额。

渠道培训建议每只新产品销售前一次，每半年复训。抽检录音中若出现“保本”“当股票买稳赚”，立即停售整改。

## 7. 与母行、托管、代销的接口

- 母行：客户风险评级、销售系统产品标签（固收类、含转债、不投股票）。
- 托管：转债券种参数、转股、赎回、回售的清算路径测试。
- 代销：提供风险评级方法说明；接受孰高；提供统一话术，不允许代销自行写成“稳健股票”。
- 登记中心 / 中国理财网：信披字段中投资范围含转债，定期报告能穿透到券。

## 8. 12 个月里程碑

| 时间 | 里程碑 |
| --- | --- |
| 第 1–2 月 | 制度、系统拦截、核心池 v1、投委会通过 P1.0 |
| 第 3 月 | P1.0 完成登记与募集 |
| 第 4–6 月 | 完成至少一个开放/持有周期，强赎桌面演练两次 |
| 第 7–9 月 | 归因稳定、视情况打开 M2；决定是否评 R2 维持或上修 |
| 第 10–12 月 | 复盘后决策：维持、上 P1.5，或暂缓 |

一年结束时，成功的定义不是转债规模行业领先，而是：**公司拥有一套别人能接手的转债作业系统。**

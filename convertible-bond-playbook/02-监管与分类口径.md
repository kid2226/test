# 02 监管与分类口径

本页只回答四个问题：转债能不能买、算哪一类资产、放进哪一类产品、有哪些明确禁区。口径冲突时，**合同与监管报表跟外规，风险限额跟内控**。

## 1. 直接法律依据

| 文件 | 与转债相关的要点 |
| --- | --- |
| 《关于规范金融机构资产管理业务的指导意见》（资管新规） | 产品按投资性质分为固定收益类、权益类、商品及金融衍生品类、混合类。固定收益类要求投资于存款、债券等债权类资产的比例不低于 80%。 |
| 《标准化债权类资产认定规则》 | 永续债、可转债：根据企业会计准则及发行机构会计归属，**明确为债权的属于标债资产**；不属于债权的，维持现行监管要求，且不按非标处理。 |
| 《商业银行理财业务监督管理办法》 | 发行前须在全国银行业理财信息登记系统登记并取得编码；公募销售前 10 日登记，私募销售前 2 日登记。净值化管理，不得保本保收益。 |
| 《商业银行理财子公司管理办法》 | 公募理财主要投资标准化债权类资产以及上市交易的股票；不得投资未上市企业股权（另有规定除外）。全部开放式公募持有单一上市公司流通股不得超过 15%。 |
| 《关于规范现金管理类理财产品管理有关事项的通知》 | 现金管理类产品**不得投资股票、可转换债券、可交换债券**。 |
| 《可转换公司债券管理办法》及沪深交易所交易细则、自律监管指引 | 上市首日有效申报价格范围、次日起 20% 涨跌幅、异常波动标准、下修预先披露、最后交易日“Z”标识等。 |
| 《资产管理产品相关会计处理规定》/ IFRS9 思路 | 可转债内嵌转股期权，通常难以通过 SPPI 测试，**不能按摊余成本计量**，须公允价值计量。 |
| 《银行保险机构资产管理产品信息披露管理办法》及理财登记中心配套 | 说明书、净值、定期报告、重大事项披露；公募产品应接入中国理财网统一信息披露平台（按最新施行安排执行）。 |
| 中国银行保险资产管理业协会《理财公司产品适当性管理自律规范》（2026） | 产品至少五级风险评级；混合类原则上不低于 R3，权益类原则上不低于 R4；代销与管理人评级不一致时按孰高。 |

## 2. 产品四分类与转债的位置

资管新规的分类看的是**资产法律属性占比**，不是波动率：

| 产品类型 | 监管定义 | 转债怎么放 |
| --- | --- | --- |
| 固定收益类 | 债权类资产 ≥ 80% | 会计属性为债权的可转债，外规通常计入这 80%。这是起步产品的主战场。 |
| 权益类 | 股票、未上市股权等权益类资产 ≥ 80% | 转债不是用来凑这项的。未转股前不要按股票统计。 |
| 商品及金融衍生品类 | 商品及衍生品 ≥ 80% | 与转债主线无关。 |
| 混合类 | 任一类别都未达到 80% | 当转债之外还要明显配股票、商品或衍生品，或债权类主动降到 80% 以下时使用。适当性上原则上不低于 R3。 |

**现金管理类**是另一套规则：即使产品名字不叫“现金”，只要每个交易日可申赎且只投资货币市场工具，或名称含“货币/现金/流动”等，就不得配转债。

## 3. 必须拆开的两本账

### 3.1 外规账：产品分类与合同比例

- 可转债在未转股前，按债券/债权资产列示。
- 固收类产品：债权类（含转债）≥ 80%；可以约定“不直接投资二级市场股票、不参与打新”。
- 转债转股后，股票计入权益类资产。要在系统里设**转股自动预警**，防止固收类产品因转股被动变成混合类。
- 集中度仍适用理财产品一般限制，例如单只证券市值不超过产品净资产 10%、不超过该证券市值 30% 等（以产品合同和现行监管规定为准）。

### 3.2 内控账：波动资产与风险预算

招银理财等机构的公开表述是行业共识：**外规转债是债券，内控要和股票合并看波动头寸。**

建议在风控系统单独立“含权波动资产”科目，至少包括：

1. 可转债、可交换债市值。
2. 股票、优先股（如有）。
3. 转债的 Delta 等价权益敞口（见 07）。
4. 偏股型转债（价格或平价超过阈值）的加严限额。

起步阶段建议内部限额严于合同：

| 项目 | 合同可写 | 内部先执行 |
| --- | --- | --- |
| 转债+可交换债 | ≤ 20% | ≤ 10%，观察两个完整周期后再评估上调 |
| 单只转债 | ≤ 产品净资产 10% | ≤ 3%–5%，且不超过该券余额 10% |
| 偏股型转债（价格 > 130 或平底溢价率 > 20%） | 合同可不单列 | 合计 ≤ 转债仓位的 30% |
| AA 及以下 / 主体观察名单 | 合同按信评制度 | 禁投或仅观察池 |
| 已公告强赎 | — | 必须在停止交易前处理完毕 |

## 4. 与公募基金口径不要混用

2022 年以来，公募申报债券基金、偏债混合时，窗口指导倾向把可转债计入权益头寸，并常见“转债+可交换债合计不超过 20%”。

理财子目前公开信息仍是：**监管尚未对理财产品把转债从债权中划出。** 因此：

- 不要用公募合同模板直接当理财说明书。
- 不要在宣传中写“监管认定转债不算风险资产”。
- 要在内部制度写明：一旦监管窗口指导理财产品拉齐公募口径，产品分类、风险等级、销售适当性必须重评。
- 即便外规不拉齐，内部风险预算也按“已经拉齐”来练，避免将来被动整改。

## 5. 交易与条款监管（影响投研和运营）

2022 年 8 月 1 日起沪深交易所转债交易细则要点：

- 向不特定对象发行的可转债，上市首日有效申报价格范围为较发行价 +57.3% / -43.3%，保留 20%、30% 两档盘中临停。
- 上市次日起涨跌幅 20%。
- 增设异常波动、严重异常波动标准；可要求披露或停牌核查。
- 最后交易日证券简称前加“Z”。
- 下修：预计触发条件前 5 个交易日预先披露；未按规定审议或披露的，视为本次不行使，且一定期限内不得再次行使（以届时有效自律规则为准）。

对理财子作业的含义：

- 交易台必须按债券交易通道下单，遵守涨跌幅和无效申报规则。
- 运营必须盯“Z”标识、停止交易日、赎回登记日，避免持有到被按面值附近赎回。
- 研究必须把下修预告纳入条款日历，但起步阶段不把下修博弈当核心 alpha。

个人投资者“2 年交易经验 + 10 万元资产”的适当性，约束的是投资者直接参与转债，不替代理财产品自身的适当性评级。

## 6. 估值与“平滑收益”禁区

- 可转债一般不满足摊余成本条件，须市值法（交易所收盘价或认可的第三方估值）。
- 开放式非现金管理类产品整体以市值法为主。
- 封闭式/混合估值产品中，转债仍应放在市值法篮子，不能为了平滑波动改成摊余成本。
- 2024–2025 年监管已要求整改与信托合作的收盘价估值、“平滑收益”安排。转债波动不得再通过通道、估值模型、以丰补歉来处理。

## 7. 口径决策表（投委会可直接用）

| 情形 | 产品类型建议 | 风险等级下限 | 是否允许 |
| --- | --- | --- | --- |
| 债权 ≥ 80%，转债 0–10%，不买股票 | 固收类 | R2 可论证 | 起步首选 |
| 债权 ≥ 80%，转债 0–20%，不买股票 | 固收类 | R2 或 R3，看回撤预算 | 阶段 2 |
| 债权 ≥ 80%，转债 + 少量股票/打新 | 仍可能是固收类 | 通常 R3 | 权益流程就绪后再议 |
| 债权 < 80% | 混合类 | 原则上 ≥ R3 | 不作为起步 |
| 现金管理类 | — | R1 | **禁止转债** |
| 转股后股票超过权益限额或破坏固收分类 | 触发产品转型/强制卖出条款 | 重评 | 必须有应急条款 |

## 8. 制度落地表

内部至少应有四份文件与本页对齐，名称可按公司制度体系调整：

1. 《可转债及可交换债投资管理办法》：投资范围、池、限额、转股处理。
2. 《理财产品分类与风险评级实施细则》：外规分类、R 等级、代销孰高。
3. 《公允价值估值实施细则》：转债取价、停牌、强赎、流动性折价。
4. 《异常交易与条款事件操作规程》：涨跌停/临停、强赎、回售、下修、停牌。

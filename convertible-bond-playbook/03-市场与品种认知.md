# 03 市场与品种认知

投研和产品设计共用同一套品种语言。没有这套语言，信用研究员会把转债当信用债，权益研究员会把转债当股票，产品经理会把波动讲成“市场波动正常”。

## 1. 一张转债是什么

国内公募可转债可以理解为：

**普通公司信用债 + 正股看涨期权 + 下修/赎回/回售等路径依赖条款。**

| 要素 | 市场惯例 | 对组合的含义 |
| --- | --- | --- |
| 面值 / 发行价 | 100 元 | 价格讨论以元为单位，不是净价利息口径 |
| 期限 | 以 6 年为主 | 剩余期限影响债底和条款博弈 |
| 票息 | 累进、前低后高 | 不能按票息选券，YTM 才有比较意义 |
| 转股期 | 发行结束满 6 个月 | 未进入转股期的新券期权价值仍在，但强赎通常要进入转股期 |
| 初始转股价 | 不低于公告前 20 日均价与前 1 日均价孰高 | 转股价是后续所有条款的锚 |
| 交易 | 交易所匹配成交，T+0，次日起涨跌幅 20% | 流动性好于多数信用债，也更容易被短线资金扰动 |
| 到期赎回 | 常见面值 110% 左右（含最后一年利息） | 债性券的“到期安全垫”来自这里，不是来自 100 元面值 |

## 2. 必须每日看的指标

### 2.1 债性

| 指标 | 定义 | 用法 |
| --- | --- | --- |
| 纯债价值（债底） | 未来票息、本金、到期补偿按同评级曲线折现 | 理论价格下限。信用恶化时债底也会塌 |
| 纯债溢价率 | 转债价格 / 纯债价值 - 1 | 越低，债底越厚；很高说明在为期权付费 |
| YTM | 把转债当普通债持有到期的收益率 | 债性策略的核心比较指标 |
| 评级 / 主体资质 | 债项与主体 | 理财资金先看会不会“债底失效” |

### 2.2 股性

| 指标 | 定义 | 用法 |
| --- | --- | --- |
| 转股价值（平价） | 正股价格 × 100 / 转股价 | 转债与正股的硬连接 |
| 转股溢价率 | 转债价格 / 转股价值 - 1 | 越低，正股上涨传导越充分；不同平价之间不能横比 |
| 平底溢价率 | 转股价值 / 纯债价值 - 1 | 划分偏债 / 平衡 / 偏股 |
| Delta / 等价股票敞口 | 转债价格对正股的敏感度 × 持仓 | 内控权益风险预算用这个，不用名义市值 |

### 2.3 期权与条款

| 指标 | 用法 |
| --- | --- |
| 隐含波动率 | 市场给转股期权的定价是否过贵 |
| 百元溢价率 / 拟合溢价率 | 把不同平价的溢价率拉到可比尺度，看市场估值中枢 |
| 强赎进度 | 连续 30 日中已有多少日收盘价 ≥ 转股价 130% |
| 下修进度 | 连续 30 日中已有多少日收盘价 < 转股价 85% |
| 回售进度 | 最后两个计息年度，连续 30 日 < 转股价 70% |
| 剩余规模 / 日均成交 | 理财资金容量；过小则无法作为组合底仓 |

常用条款记忆：

- **下修**：15/30，85%（董事会提议，股东大会通过）。
- **有条件赎回（强赎）**：转股期内 15/30，130%，按面值+应计利息赎回。
- **有条件回售**：最后两年，30/30，70%，持有人有权回售。

## 3. 风格三分类（组合语言）

业内常用平底溢价率 ±20%，或直接用转股价值/价格带来划分。手册统一如下，便于产品和风控使用同一套标签：

| 风格 | 经验标准 | 风险收益 | 起步阶段定位 |
| --- | --- | --- | --- |
| 偏债型 | 平底溢价率 < -20%，或价格靠近债底、转股溢价很高 | 接近信用债，弹性小，看 YTM 和信用 | **主力** |
| 平衡型 | 平底溢价率 -20% ~ +20%，价格常见 110–130 | 有债底也有一定凸性 | **增强仓** |
| 偏股型 | 平底溢价率 > 20%，或价格显著高于 130 | 近似股票，债底保护弱 | **严格限额，非起步主力** |

补充价格带（与风格交叉使用，不能单看价格）：

| 价格带 | 经验含义 |
| --- | --- |
| < 110 | 债性保护相对好，但要排除信用瑕疵和“便宜的垃圾” |
| 110–130 | 理财固收+最常用区间 |
| > 130 | 靠近强赎区，溢价压缩，波动接近正股 |
| > 150 或临近强赎 | 当作股票仓管理，并启动强赎预案 |

## 4. 收益从哪里来（以及不从哪里来）

理财资金做转债，收益来源按可靠程度排序：

1. **债底票息与到期补偿**：最像现有固收能力，波动低。
2. **估值修复**：低价、低溢价品种向中枢回归。市场整体溢价已经很高时，这一项会失效。
3. **正股驱动的凸性**：正股上涨时转债涨得跟得上、下跌时跌得少。这是“+”的意义，但依赖正股质量和买入时的溢价。
4. **条款事件**：下修、强赎前溢价压缩、回售保护。胜率不低，但对发行人动机和交易时点要求高，起步阶段只做风险处理，不做主策略。
5. **打新/抢权**：流程标准化，但对理财大资金容量有限，且抢权会引入正股波动。

明确不是稳定来源的：

- 小盘题材炒作的溢价扩张。
- 无信用安全垫的低价券反弹。
- 已公告强赎后的“再搏一把”。

## 5. 市场状态如何映射到产品

转债组合的风险，不只取决于仓位，还取决于市场处于哪一档估值和风格。产品说明书里的 0–20% 在低溢价债性市和在高价偏股市，含义完全不同。

| 市场状态 | 观察 | 产品动作 |
| --- | --- | --- |
| 债性市 | 价格中枢低、YTM 有吸引力、转股溢价高 | 可提高转债仓位，但仍选高评级；产品体验接近固收增强 |
| 平衡市 | 双低策略有效、正股有结构性机会 | 标准固收+状态，强调分散和轮动纪律 |
| 股性市 | 价格和溢价双高，转债指数跟股票走 | 降低仓位或把券下沉到仍有债底的品种；必要时把产品风险等级或话术上修 |
| 股债双杀 | 正股跌 + 转债估值杀 + 信用利差走阔 | 债底也可能失效；启动回撤预案，停止“抄底加仓”直到信用排查完成 |

2025–2026 年卖方框架的共识是：估值扩张空间有限后，收益更依赖正股质量和条款，而不是“买了转债就有不对称性”。这对权益能力偏弱的理财子更重要——**不能假设凸性总是站在持有人一边**。

## 6. 容量与流动性（理财资金特有）

散户双低策略常用 10–20 只等权、余额下限 0.3–1.5 亿元。理财资金不能直接照搬：

- 单只产品若有数十亿规模，转债 10% 就是数亿，必须看全市场可投余额和日成交。
- 建议核心池券：剩余规模足够大、日均成交能覆盖自身预计买卖而不造成显著冲击。
- 银行转债、大盘高评级转债是容量主力；小盘低溢价券只能做卫星，且要有冲击成本估计。
- 轮动频率低于散户量化：月度或双周，而不是 T+0 高频。

## 7. 与正股、股票、二级债基的差异（给产品和销售）

|  | 信用债 | 可转债 | 股票 |
| --- | --- | --- | --- |
| 下行 | 利率和信用 | 多数时候有债底，信用出事则没有 | 没有债底 |
| 上行 | 票息和利差压缩 | 有期权凸性，但强赎会截断 | 理论上不截断 |
| 定价语言 | YTM、利差 | 必须同时说债底和溢价 | 盈利和估值 |
| 客户感受 | 净值慢波动 | 有时像债，有时像股 | 波动直观 |
| 理财起步 | 已会 | 本手册 | 能力建设后再做 |

销售一句话：  
**可转债不是“更稳的股票”，也不是“更高收益的存款”，而是带期权的信用债。下跌保护来自发行人还钱的能力，上涨弹性来自正股，两者缺一不可。**

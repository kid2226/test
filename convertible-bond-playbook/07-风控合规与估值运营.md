# 07 风控合规与估值运营

转债业务的风控目标不是“消灭波动”，而是：**波动可计量、超限可拦截、事件可处理、估值可解释、披露可追溯。**

## 1. 风险地图

| 风险 | 表现 | 主控 |
| --- | --- | --- |
| 市场风险 | 正股下跌、转债估值压缩、利率上行叠加 | 仓位、风格、Delta 限额 |
| 信用风险 | 债底失效、评级下调、违约 | 入库、禁投、同一发行人合并 |
| 流动性风险 | 小券冲击成本、开放日变现 | 余额门槛、分散、开放结构 |
| 条款风险 | 强赎按面值赎回、回售、下修不确定性 | 日历、强制处理 |
| 合规分类风险 | 转股后变成混合类、现金管理类误配 | 系统监测 |
| 操作风险 | 错价、漏公告、超限下单 | AB 角、拦截 |
| 销售适当性风险 | 当纯债卖、承诺收益 | 话术审核、录音质检 |
| 估值风险 | 停牌、异常波动日取价争议 | 估值委员会 |
| 声誉风险 | 净值大幅回撤引发客诉 | 风险预算 + 陪伴 |

## 2. 限额框架（内部严于合同）

建议风控台账至少这些维度。数字是起步建议，最终以风险委员会决议为准。

### 2.1 产品层

| 限额 | P1.0 建议 | 监控频率 |
| --- | --- | --- |
| 转债+可交换债市值 / 净资产 | 内部 ≤ 10%，合同 ≤ 20% | 日 |
| 偏股型转债 / 转债市值 | ≤ 30% | 日 |
| 转债桶从高点回撤 | 达到预警线降仓，达到止损线降到中枢以下 | 日 |
| 产品最大回撤（年度） | 立项确定 | 日 |
| 杠杆 | 不超过监管与合同 | 日 |
| 现金及高流动性资产 | 满足开放式流动性比例 | 日 |

### 2.2 个券与发行人

| 限额 | 建议 |
| --- | --- |
| 单只转债 / 产品净资产 | 3%–5%（合同 10%） |
| 单只转债持仓 / 该券剩余规模 | ≤ 10%，大额还须评估冲击 |
| 同一发行人信用债+转债合计 | 纳入统一发行人限额 |
| 最低评级 | AA+（观察名单单独批） |
| 最低剩余规模 | 核心池门槛，例如 5 亿元 |

### 2.3 Delta 等价权益（内控关键）

名义转债仓位 10%，如果全是高价偏股券，等价股票敞口可能接近 8%–10%；如果全是深度债性券，等价敞口可能只有 1%–3%。

因此内部除名义市值外，增加：

```text
等价权益敞口 ≈ Σ (转债市值 × 估计 Delta)
```

Delta 可用卖方风险值、内部简化表（偏债 0.1–0.3，平衡 0.3–0.6，偏股 0.6–0.9）或定价模型。起步可用简化表，但必须书面、保守。

P1.0 建议：等价权益敞口不超过产品净资产 5%。这比名义 10% 更能防止风格漂移。

## 3. 监测与升级

| 状态 | 触发 | 动作 |
| --- | --- | --- |
| 绿 | 各项限额 80% 以内 | 正常 |
| 黄 | 任一限额 80%–100%，或条款进入关注 | 投资经理书面说明，风控知情 |
| 橙 | 触及内部限额、回撤预警、分类预警 | 停止加仓，必须减仓计划 |
| 红 | 超内部限额、强赎未处理、信用事件、可能破坏固收分类 | 风控一票否决，向有权人报告 |

超合同限额属于合规事件，须按公司违规处理，不能用“准备明天卖掉”口头带过。

## 4. 估值操作

1. **活跃转债：** 交易所收盘价。
2. **盘中临停但收盘恢复：** 按收盘价；全天停牌：按最近收盘价或第三方估值，由估值政策规定，并评估是否需流动性调整。
3. **异常波动日：** 仍以市场价为准，不得改用模型把净值“做平”。
4. **强赎公告后：** 价格会向赎回价收敛，按市价，同时投资侧必须交易。
5. **转股：** 按股票估值政策；在途转股有清算时间差，运营须有在途科目。
6. **新债上市首日：** 涨跌幅规则与次日不同，核对行情源。

估值委员会在停牌超过一定天数、无可靠报价、或第三方估值偏离过大时召开。会议记录与净值调整留痕。

**禁止：** 收盘价指定、平滑信托、用内部模型替代活跃市场报价、把转债放进摊余成本桶。

## 5. 合规要点清单

- 现金管理类产品投资范围黑名单含转债、可交换债。
- 未登记不得销售；编码必须出现在销售文件显著位置。
- 公募主要投资标债和上市股票；转债作为标债（债权属性）配置。
- 关联交易、集中度、杠杆按理财办法及合同。
- 宣传材料不得预测收益、不得与存款对比成“替代存款且更高收益”而不揭示波动。
- 适当性：评级、匹配、双录（如适用）、代销孰高。
- 信息披露：成立、净值、定期报告、重大事项时点见 02 与 06。
- 监管口径若将转债改计权益，启动产品重评预案（分类、R 等级、销售暂停评估）。

## 6. 运营日终检查（可系统化）

见 [T04](templates/T04-日常风控检查清单.md)。最低人工确认项：

1. 今日是否有持仓券公告。
2. 是否有 Z 标识或停止交易。
3. 转债仓位、单券、偏股占比、等价权益。
4. 估值价格是否异常（相对昨收涨跌幅、相对债底）。
5. 是否发生转股、回售、赎回。
6. 明日开放日准备。

## 7. 压力测试（每季）

至少三组：

1. 转债指数下跌 10%，纯债不变。
2. 信用利差走阔 50bp + 转债价格向债底回落。
3. 最大两只转债连续跌停/临停，开放日遭遇 10% 赎回。

测试结果若突破产品风险预算，必须在当季降低中枢仓位或缩短偏股暴露，而不是等到回测“以后很少发生”。

## 8. 审计与留痕

至少保存：

- 入池审批与否决记录。
- 个券一页纸（T02）与退出条件触发记录。
- 超限与强赎处理全流程。
- 投委会材料与决议。
- 销售培训记录与话术版本号。
- 估值例外审批。

保存期限遵循公司档案和监管要求。

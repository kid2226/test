# 附录：资料索引与口径来源

本手册是工作流程，不是法律意见。落地时以届时有效的监管规定、公司制度和产品合同为准。下列来源用于说明“为什么这么设计”。

## 2. 行业实践（产品与组织）

| 来源 | 用到的结论 |
| --- | --- |

## 3. 投研框架（卖方与方法论，用于指标定义）

| 来源 | 用到的结论 |
| --- | --- |
| 天风证券《转债四维分析手册》（2026） | 股 / 债 / 期三维；平底溢价划分风格；条款与强赎溢价 |
| 华创证券可转债投资手册系列 | 债性/股性指标、隐含波动率、百元溢价、分析顺序 |
| 国金证券转债量化研究（低价与双低） | 低价偏绝对收益、双低偏弹性；溢价中枢上移后须改造 |
| 转债下修博弈专题（2026） | 下修动机与时点；手册将其降为非起步主策略 |

双低公式 `价格 + 转股溢价率×100` 是市场约定算法，不是监管规定。理财资金使用时必须叠加信用、流动性和价格上限。

## 4. 公募与理财的口径差（避免误用）

2022 年以来公募债券基金、偏债混合申报中，窗口指导倾向将可转债计入权益并限制 20%。理财产品尚未普遍拉齐。手册采取：

- 合同分类按现行理财外规（债权）。
- 内部风险预算按“视同已拉齐”管理。
- 一旦窗口指导理财产品，启动 02 章重评预案。

## 5. 使用与更新

- 引用监管条款请核对原文最新修订。
- 产品要素数字（10%、20%、AA+、5 亿元余额等）是起步建议，须经本公司风险委员会确认后写入制度。
- 建议每半年对照协会自律规范、交易所规则和公司产品目录更新一次本附录。

# 01 战略定位：用可转债承接权益短板

## 1. 问题定义

理财子当前的约束是三句话同时成立：

1. **负债端**要稳健：母行零售客群对回撤、负收益天数、业绩比较基准的敏感度显著高于公募权益持有人。
2. **资产端**票息变薄：利率下行、信用利差压缩后，纯债和传统非标已经很难单独支撑有竞争力的绝对收益。
3. **能力端**权益偏弱：缺的不是“能不能买股票”的牌照，而是个股研究、回撤归因、权益交易纪律和客群沟通。

在这个约束下，直接上主动权益或高仓位混合类产品，失败模式通常是：净值回撤超出客群容忍 → 赎回负反馈 → 投研被市场教育 → 产品线收缩。可转债的战略价值，是把“含权”这件事拆成可训练、可限额、可解释的模块。

## 2. 可转债在能力图谱中的位置

```text
纯债 / 现金管理     固收+转债     固收+红利/指数     混合类含权      主动权益
    |                 |                 |                |              |
 票息与流动性      债底+有限凸性      需要正股定价      需要行业配置    需要完整股票投研
 现有优势区        当前切入点        下一阶段可选      能力达标后再做   不作为起步目标
```

可转债不是权益的替代品，而是权益能力的**过渡资产**和**风险预算训练场**：

| 能力 | 纯债已具备 | 转债可迁移 | 主动权益还缺 |
| --- | --- | --- | --- |
| 发行人信用分析 | 有 | 直接复用 | 还要产业和公司治理 |
| 条款与事件跟踪 | 部分（含权债） | 必须补齐 | 财报与催化剂 |
| 量化筛选与轮动 | 可快速建立 | 核心抓手 | 只能作为辅助 |
| 回撤归因 | 利率/信用 | 利率+信用+正股+估值 | 行业/风格/个股 |
| 客户沟通 | 基准与票息 | 要解释“为什么不是股票却会波动” | 要解释亏损和风格 |

## 3. 战略目标（可验收）

首期不以规模最大化为目标，而以“产品表现符合说明书、风控可解释、流程可复制”为目标。

| 维度 | 12 个月内的验收标准 |
| --- | --- |
| 产品 | 至少 1 只固收类“固收+转债”产品完成登记、募集、一个完整开放/持有周期 |
| 风险 | 产品最大回撤、负收益天数落在立项时的风险预算内；未出现强赎漏处理、信用踩雷 |
| 投研 | 形成可转债核心池、观察池、禁投池；个券有一页纸备忘录 |
| 组织 | 明确投资经理、信用研究、交易、风控的职责；投委会可独立审议转债仓位 |
| 销售 | 渠道话术不把转债产品讲成“稳健纯债”或“稳赚股票” |
| 进阶 | 复盘后才决定是否提高转债上限或引入股票/红利 |

## 4. 先做与不做

### 先做

- 固收类产品中的可转债增强，上限先按 **0–10%** 运行，合同上限可写 20%，内部风险预算更严。
- 高评级、有债底、余额足够的品种；银行、公用事业等高分红正股对应的债性/平衡型转债优先。
- 规则化筛选 + 信用排雷 + 条款日历，减少对个股观点的依赖。
- 持有期或最短持有期产品，降低每日开放对转债波动的放大。

### 明确不做（起步阶段）

- 现金管理类产品配置转债。
- 把转债当小盘股炒作：低评级、小余额、高价高溢价、题材炒作券。
- 以下修博弈、抢权配债、打新博傻作为主力策略。
- 未建股票研究团队时，直接上“转债+主动选股”混合类产品。
- 用估值平滑、收盘价调整、信托通道等方式掩盖波动。
- 为冲规模把转债仓位顶到合同上限，或把业绩比较基准定得像权益产品。

## 5. 与同业路径的对照

行业里已经走通的，不是“转债专家团队一夜建成”，而是把转债放进固收+工具箱：

- **光大理财**曾发行固收类“固收+可转债”产品：不直接二级市场买股票、不参与打新，转债比例不超过 20%，风险等级 R2。这是最贴近起步阶段的产品形态。
- **汇华理财**等用较长期限封闭产品承载转债策略，换取管理人的持有期和条款博弈空间。
- **平安理财、交银理财、施罗德交银理财**等把转债与红利、REITs、量化中性、ETF 并列，作为含权工具而不是单一押注。
- **信银理财**把转债做成策略模块，放进“投资工厂”，强调可装配、可复制，而不是投资经理个人风格。

对本手册的含义：起步产品应对标“光大路径”（固收类、不买股票、转债有上限），组织建设应对标“信银路径”（策略模块化），而不是对标公募二级债基的高弹性转债基金。

## 6. 成功与失败的早期信号

**健康信号**

- 转债贡献正的收益增强，但组合波动仍主要由利率和信用解释。
- 客户赎回与债市调整相关，而不是与转债单日涨跌相关。
- 投研周报能说清：仓位、风格（债性/平衡/股性）、前五大券、强赎倒计时、信用观察名单。

**危险信号**

- 为了“跟上基准”把仓位从债性券迁到高价偏股券。
- 说明书写固收类，销售讲“能赚钱的股票替代”。
- 出现余额过小券、评级边缘券、已公告强赎仍持有。
- 回撤超预算后，第一反应是改估值而不是降仓或拉长持有期。

出现危险信号时，回到阶段 1：收紧风格、降低上限、重做客户沟通，而不是用新产品覆盖旧问题。

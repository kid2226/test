# 多国多模型协作方案

用多个不同国家、不同厂商的大模型解决问题：发挥各自特长；简单题走快路；难题让它们**同时独立思考**，再对照分歧。

| 文件 | 内容 |
|---|---|

| [速查卡.md](./速查卡.md) | 一页纸决策 |
| [并行议会提示词.md](./并行议会提示词.md) | Brief / 独立作答 / 质询 / 合成，复制即用 |
| [roster.yaml](./roster.yaml) | 席位与路由配置 |

**先这样开始：** Claude + GPT + DeepSeek，再配一个中文长文入口（Kimi 或千问）。没想明白的问题，把同一份 Brief 同时发给这三家，用对照表看共识和分歧，不要让后问的看到先问的答案。

## 30 秒决策

```
语言/国别 → 任务轴 → 错了代价大不大 → 要一个答案还是多种方案
         ↓
    低代价可验证     →  1 个最合适的模型
    高代价可验证     →  王牌干活 + 另一国模型审核
    高代价不可验证   →  3–5 席并行议会
    只要多样性       →  议会，但不要合成成一篇
```

## 默认 3 席议会

1. **全球通：** Claude 或 GPT  
2. **中国通：** DeepSeek 或千问  
3. **第三源：** Gemini / Grok / Mistral / Kimi（换一家，打破中美二元）

规则：必须不同公司；第一轮互相看不见；合成器用没参加第一轮的，或你自己合成。

## 并行七步

1. 写同一份 Brief  
2. 同时发给各席  
3. 独立结构化作答  
4. 填：共识 / 分歧 / 独有洞察 / 不确定点  
5. 分歧大 → 质询一轮；共识高 → 跳过  
6. 合成器保留分歧，禁止假装统一  
7. L4 必须人签字  

## 对照时怎么读

| 现象 | 含义 | 动作 |
|---|---|---|
| 结论+假设都一致 | 较稳 | 抽查一条关键证据 |
| 结论同、假设不同 | 假共识 | 统一假设再问 |
| 结论冲突 | 议会成功 | 写成情景，去查，不按名气投票 |
| 只有一家提的点 | 幻觉或真洞察 | 让另外两家单独评价该点 |
| 某家拒答 | 对齐政策，不是事实 | 换一国模型，标注口径差 |

## 不要做

- 三个窗口都开 GPT  
- 每件小事都并行  
- 让后发言的看到先发言的答案  
- 用排行榜加权投票  
- 把未公开数据贴进会训练的免费聊天  
- 用“模型都说可以”代替你签字

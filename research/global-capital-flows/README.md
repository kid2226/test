## 核心结论（一句话）

过去两百年资本先跟着帝国和铁路走，再跟着官方重建走，再跟着石油和亚洲工厂走。21 世纪前二十年是“工厂在中国、储蓄进美国”。近五年工厂开始分散，储蓄却更集中地进入美国——中国转为重要资本输出国，而不再是全球增量资本的首选目的地。

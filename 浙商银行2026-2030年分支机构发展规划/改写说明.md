# 从建议报告到规划文稿的改写说明

本稿依据《“五五”期间网点规划建议报告》（2026年6月7日，部门审定、区域修订稿）改写，形成面向分行的《浙商银行2026—2030年分支机构发展规划》初稿。

## 一、结构对照

| 原建议报告 | 是否进入规划正文 | 处理 |
| --- | --- | --- |
| 全文帽段 + 第四部分帽段 | 是 | 融合为规划帽段，去掉“行领导”“我部建议”“测算摆布”等汇报口径 |
| 第一部分 同业网点发展态势 | 否 | 决策参考，不下发分行 |
| 第二部分 现有网点效能分析 | 否 | 决策参考，不下发分行 |
| 第三部分 网点建设与业务规模关系 | 否 | 决策参考，不下发分行 |
| 第四部分 网点规划建议 | 是 | 改为规划安排；重点分行由长段落改为“一句依据+数量+区域” |
| 第五部分 网点规模与营收测算 | 否 | 测算不下发；2030年末网点数纳入附件 |
| 第六部分 网点人员与成本测算 | 否 | 测算不下发；人员配置原则压缩进工作要求 |
| 第七部分 相关工作建议 | 部分 | 见下文取舍 |
| 附件1 分行主要指标测算表 | 否 | 营收、净息差情景仅供行领导 |
| 附件2 网点规划汇总表 | 是 | 按第四部分重编为发文附件（原Word中该表未随文） |

## 二、帽段融合要点

保留并合并的内容：规划目标、存量效能、监管准入、加快省内布局、重点区域加密、兼顾其他区域、一级/二级分行落地、适度撤并、省内净增44家、省外净增86家、2030年末500家。

删去或改写的内容：称谓“行领导”、部门口吻“我部提出”、测算资产存款营收人员、“拟规划”“计划”等请示用语。

增加的内容：网点口径不含2家专营机构；分行规划数量为控制数；区县布局可沟通、数量不得重新开口。

## 三、语气调整

- “拟”“预计”“乐观预计”“建议”“力争”改为“规划”“安排”“明确”“要”。
- 对分行由“建议报告”改为“规划安排+工作要求”。
- 区县名称保留为布局导向，并写明不是最终选址清单。

## 四、第七部分取舍

- **（二）大行挑大梁**：纳入，作为工作要求第二条；去掉“反哺浙江”“市场潜力远超省内”等内部建议口径。
- **（一）监管沟通**：纳入，适合作为对分行的任务。
- **（三）存量挖潜**：保留方向，删除60%、40%、53%等内部诊断数据。
- **（四）人员编制、（五）费用支出**：原则纳入，删除“四级管理”“控制行员等级”等越权表述，改为执行总行相关部门制度。

## 五、使用方式

1. 对外/对分行使用：`浙商银行2026-2030年分支机构发展规划.docx`
2. 对内改稿使用：`发展规划初稿审阅意见.docx`（发展规划部领导视角的具体修改点，不随规划下发）

发文前仍须补齐省内12家、省外12家和在筹14家的分行分解数，并按审阅意见完成会签和口径核对。

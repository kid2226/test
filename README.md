## 创新点

不是记一次逛菜场的流水账，而是画三张会呼吸的地图：

1. **地理疆域**：家和学校之外，多了东山弄这个坐标
2. **感官疆域**：用眼耳鼻舌心重新认识杭州
3. **人情疆域**：第一次被当成会买菜的人

另外用“镜像”对照：菜场自己也在扩疆（农贸市场 → 一菜一早 → 邻里共生），和初一新生的成长叠在一起。西湖鱼“开盲盒”则是整场演讲的核心比喻。

## 使用建议

1. 用 PowerPoint 或 WPS 打开课件，封面“演讲人”处填上姓名。
2. 先把 `演讲稿.txt` 读两遍，再对着课件练；演示者视图里每页都有要点。
3. 如果老师要求必须是亲身经历，请按自己当天的真实路线、对话和小吃，改一两处细节。
4. 语速放慢，大约 4 分半到 6 分钟。

需要重新生成课件时，可运行：

```bash
python3 build_ppt.py
```

# 中国债券与股票资产比较研究

本仓库收录一份面向从业者的大类资产配置研究报告，系统比较中国债券资产与股票资产的理论、市场结构、风险收益与投研范式。

**推荐阅读 Word 版**（封面、目录、导航标题、页码与配图已嵌入，可用 Word 左侧导航窗格跳转）：

- [`reports/中国债券与股票资产比较研究报告.docx`](reports/中国债券与股票资产比较研究报告.docx)

其他文件：

- Markdown 源文件：[`reports/中国债券与股票资产比较研究报告.md`](reports/中国债券与股票资产比较研究报告.md)
- 配图：[`reports/figures/`](reports/figures/)
- 重导脚本：`python3 scripts/md_to_docx.py`

报告把股债比较放在四条轴上展开：权利与定价、市场结构、风险收益、相关与轮动；给出战略配置—战术配置—底层构建的三层工作台，以及银行、保险、公募、外资和个人投资者的约束差异。关键数据来自人民银行、中国结算、国家统计局及 SBBI 框架下的中国长期收益统计，并标注口径。
